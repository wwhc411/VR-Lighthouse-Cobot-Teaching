## 1. 功能需求概述

### 1.1 功能目标

实现一个**刚体位姿日志打印组件**，用于：

- ✅ 实时输出Nokov软件捕获的刚体**位置数据** (Position: X, Y, Z)
- ✅ 实时输出Nokov软件捕获的刚体**姿态数据** (Orientation: 四元数/欧拉角)
- ✅ 支持输出到Unity Console控制台
- ✅ 支持输出到外部日志文件
- ✅ 可配置日志输出频率
- ✅ 可选择特定刚体进行监控

### 1.2 应用场景

| 场景 | 描述 |
|------|------|
| 调试验证 | 验证Nokov与Unity的数据通信是否正常 |
| 数据分析 | 记录刚体运动轨迹用于后续分析 |
| 问题排查 | 定位数据丢失、延迟等问题 |
| 开发测试 | 观察刚体位姿变化规律 |

│                     Nokov Unity Plugin                          │

### 2.2 核心数据结构

#### NokovPose - 位姿数据结构

```csharp
public class NokovPose
{
    public Vector3 Position;       // 位置坐标 (x, y, z)
    public Quaternion Orientation; // 姿态四元数 (x, y, z, w)
}
```

#### NokovRigidBodyState - 刚体状态

```csharp
public class NokovRigidBodyState
{
    public NokovHiResTimer.Timestamp DeliveryTimestamp; // 数据接收时间戳
    public NokovPose Pose;                               // 位姿数据
}
```

#### NokovRigidBodyDefinition - 刚体定义

```csharp
public class NokovRigidBodyDefinition
{
    public Int32 Id;    // 刚体ID
    public string Name; // 刚体名称
}
```

### 2.3 关键接口方法

#### StreamingClient 类提供的接口

| 方法 | 返回类型 | 描述 |
|------|----------|------|
| `FindDefaultClient()` | `StreamingClient` | 查找场景中的默认客户端 |
| `GetLatestRigidBodyState(string rigidBodyName)` | `NokovRigidBodyState` | 根据刚体名称获取最新状态 |
| `GetRigidBodyDefinitionById(int id)` | `NokovRigidBodyDefinition` | 根据ID获取刚体定义 |
| `GetRigidBodyDefinitionByName(string name)` | `NokovRigidBodyDefinition` | 根据名称获取刚体定义 |

#### 坐标转换方法

| 方法 | 描述 |
|------|------|
| `NokovToUnityTranslation(float x, float y, float z)` | 将Nokov坐标转换为Unity坐标 |
| `NokovToUnityQuaternion(float x, float y, float z, float w, E_UpAxis upAxis)` | 将Nokov四元数转换为Unity四元数 |

## 4. 详细设计方案

### 4.1 类设计

```csharp
public class RigidBodyPoseLogger : MonoBehaviour
{
    // ================= 配置参数 =================
    
    [Header("数据源配置")]
    [Tooltip("Nokov数据流客户端引用，留空则自动查找")]
    public StreamingClient streamingClient;
    
    [Tooltip("要监控的刚体名称列表")]
    public string[] targetRigidBodyNames = new string[] { };
    
    [Tooltip("是否监控所有刚体")]
    public bool logAllRigidBodies = true;
    
    [Header("日志输出配置")]
    [Tooltip("日志输出间隔(秒)，0表示每帧输出")]
    [Range(0f, 5f)]
    public float logInterval = 0.5f;
    
    [Tooltip("是否输出到Unity控制台")]
    public bool enableConsoleLog = true;
    
    [Tooltip("是否输出到文件")]
    public bool enableFileLog = false;
    
    [Tooltip("日志文件名(自动添加时间戳)")]
    public string logFileName = "RigidBodyPose";
    
    [Header("格式配置")]
    [Tooltip("是否显示欧拉角(否则显示四元数)")]
    public bool showEulerAngles = true;
    
    [Tooltip("位置数据小数位数")]
    [Range(1, 6)]
    public int positionDecimalPlaces = 4;
    
    [Tooltip("角度数据小数位数")]
    [Range(1, 4)]
    public int rotationDecimalPlaces = 2;
    
    [Tooltip("显示时间戳")]
    public bool showTimestamp = true;
    
    // ================= 私有变量 =================
    private float lastLogTime;
    private StreamWriter fileWriter;
    private string fullLogPath;
    private int frameCount;
}
```

## 6. 使用说明

### 6.1 快速开始

1. **添加组件**
   - 将`RigidBodyPoseLogger`脚本拖到任意GameObject上
   - 或者添加到已有的`Client - Nokov`预制体上

2. **配置参数**
   - `Streaming Client`: 拖入场景中的StreamingClient对象(可留空自动查找)
   - `Target Rigid Body Names`: 填写要监控的刚体名称
   - `Log All Rigid Bodies`: 勾选则监控所有刚体
   - `Log Interval`: 设置日志输出间隔

3. **运行查看**
   - 运行游戏
   - 在Console窗口查看日志输出
   - 如果启用文件日志，在指定路径查看CSV文件

### 6.4 常见问题

| 问题 | 解决方案 |
|------|----------|
| 没有日志输出 | 检查StreamingClient是否已连接到Nokov服务器 |
| 刚体数据为空 | 确认Nokov软件中已创建并激活刚体 |
| 文件写入失败 | 检查目录权限，确保路径存在 |
| 性能下降 | 增大Log Interval值，减少日志频率 |
