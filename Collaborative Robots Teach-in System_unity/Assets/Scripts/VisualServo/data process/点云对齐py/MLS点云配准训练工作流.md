# 点云配准训练流程与原理详解 (MLS + Chord Spatial)

本文档描述了当前配置下（`tunable_registration.py`）使用 **MLS (移动最小二乘)** 算法配合 **Chord Spatial (真3D弦距重采样)** 进行点云配准训练的完整工作流程。

## 流程详解

### 1. 数据准备
*   **加载数据**: 分别读取 Tracker（源）和 TCP（目标）的原始轨迹 CSV 文件。
*   **预平滑检查**: 
    *   如果使用 `chord_spatial` (当前配置)，**跳过预平滑**。因为弦距采样自身能抵抗“海岸线效应”带来的噪声弧长累积，无需预先模糊数据。
    *   如果使用旧版 `adaptive_spatial`，则需在此步骤开启预平滑。

### 2. 轨迹对齐与预处理
*   **真3D弦距重采样 (Chord Spatial)**: 
    *   **密集插值**: 先将离散点加密（如50倍）。
    *   **弦距采样**: 从起点开始，用圆规“跨步”行走，只有当直线距离（弦长）达到阈值 $\Delta d$ 时才采样。
    *   **优势**: 彻底消除噪声造成的路径长度虚高（海岸线悖论），确保 Source 和 Target 的采样点在几何上真正对应。
*   **后处理平滑**: 对重采样后的轨迹进行高斯平滑（sigma=2.0），消除微小的高频抖动，为 MLS 提供更干净的输入。

### 3. MLS配准核心流程 (移动最小二乘)
*   **RANSAC异常值预剔除**: 在计算变形场之前，先用刚性 RANSAC 剔除那些“飞点”或严重不匹配的区域（如 Tracker 丢失造成的跳变），防止它们拉坏变形场。
*   **带宽选择 (LOOCV)**: 
    *   使用 **留一交叉验证 (Leave-One-Out Cross-Validation)** 自动寻找最优带宽 $h$。
    *   $h$ 决定了变形场的“刚性程度”：$h$ 越大越接近刚体，$h$ 越小越柔软（但也越容易过拟合）。
*   **端点镜像延伸**: 将轨迹首尾两端的数据向外镜像延伸 10%，解决 MLS 在边界处因邻居不足导致的变形发散问题。
*   **预计算网格变换**: 为了加速复用，不在复用时对每个点单独计算 MLS（太慢），而是预先计算 200 个均匀分布的网格点的变换矩阵。复用时只需对网格结果插值。

### 4. 评估与导出
*   **全量应用**: 将计算出的 MLS 变形场应用回所有的 729 个采样点。
*   **误差统计**: 计算 RMSE (均方根误差)、最大误差等指标。
*   **异常值最终剔除**: 统计配准后的残差，再次剔除统计上的异常值（如超过 95% 分位数），得到更客观的精度报告。
*   **导出结果**: 生成 `mls_transform.json`（包含网格变换矩阵）和 `error_plot.png`。
