## 🔍 修复了什么?

### 修改文件
- `myDll\myDll.cpp` (第165-174行)

### 具体修改

**修复前** (会崩溃):
```cpp
std::vector< cv::Mat > R_gripper2base(num_poses);  // ❌ 创建23个空Mat
R_gripper2base.push_back(mat);  // 追加到索引23,前23个空Mat导致崩溃
```

**修复后** (正常工作):
```cpp
std::vector< cv::Mat > R_gripper2base;
R_gripper2base.reserve(num_poses);  // ✅ 只预留容量,不创建空元素
R_gripper2base.push_back(mat);  // 追加到索引0,数据正确
```
