### 4. 结构体构造 (DllStructures.cs)

#### FromCameraPose函数:
```csharp
public static Pose_Unity FromCameraPose(
    double x, double y, double z,      // 位置
    double qx, double qy, double qz, double qw) // 四元数
{
    Vector3D_Unity position = new Vector3D_Unity(x, y, z);
    
    // ⭐ 关键: 构造Quaternion_Unity时使用 (w, x, y, z) 顺序
    Quaternion_Unity rotation = new Quaternion_Unity(qw, qx, qy, qz);
    
    rotation.Normalize();
    return new Pose_Unity(position, rotation);
}
```

#### Quaternion_Unity结构体定义:
```csharp
[StructLayout(LayoutKind.Sequential)]
public struct Quaternion_Unity
{
    public double w;  // ⭐ w在第1位
    public double x;  // x在第2位
    public double y;  // y在第3位
    public double z;  // z在第4位

    // 构造函数参数顺序: (w, x, y, z)
    public Quaternion_Unity(double w, double x, double y, double z)
    {
        this.w = w;
        this.x = x;
        this.y = y;
        this.z = z;
    }
}
```

**内存布局**: 
```
[StructLayout(LayoutKind.Sequential)] 确保字段按声明顺序存储:
| w (8 bytes) | x (8 bytes) | y (8 bytes) | z (8 bytes) |
| offset 0    | offset 8    | offset 16   | offset 24   |
```

## 📝 完整数据格式规范

### 机器人位姿数据 (Gripper→Base)

**格式**: 6DOF `[X, Y, Z, RX, RY, RZ]`

- **X, Y, Z**: 位置（毫米）
- **RX, RY, RZ**: 旋转向量（弧度, Rodrigues表示）

**示例**:
```
[-305.95, -500.34, 265.44, 2.4314, -1.1746, 0.2206]
```

### 相机位姿数据 (Target→Cam)

**格式**: 7DOF `[X, Y, Z, QX, QY, QZ, QW]`

- **X, Y, Z**: 位置（毫米）
- **QX, QY, QZ**: 四元数虚部
- **QW**: 四元数实部

**示例**:
```
[123.45, -234.56, 345.67, 0.1234, -0.2345, 0.3456, 0.8944]
```

**重要**: 
- 日志输出: `qx, qy, qz, qw` (虚部在前)
- DLL接收: 自动转换为 `(w, x, y, z)` 内存布局

## 📚 技术参考

### 四元数约定对比

| 库/框架 | 构造函数顺序 | 内存顺序 | 备注 |
|--------|-------------|---------|------|
| **Unity** | `(x,y,z,w)` | `{x,y,z,w}` | 虚部在前 |
| **Eigen** | `(w,x,y,z)` | `{x,y,z,w}` | 构造参数w在前,内存x在前! |
| **你的DLL** | `(w,x,y,z)` | `{w,x,y,z}` | 统一w在前 |
| **OpenCV** | 不使用四元数 | - | 使用旋转矩阵/向量 |

⚠️ **注意**: Eigen的内存顺序与构造函数参数顺序不同!
```cpp
Eigen::Quaterniond q(w, x, y, z);  // 构造参数
// 但内部存储: q.coeffs() = [x, y, z, w]  // 内存顺序!
// 访问时: q.w(), q.x(), q.y(), q.z()      // 按语义访问
```

由于你的代码使用 `.w`, `.x`, `.y`, `.z` 语义访问,而不是直接访问内存,所以不受Eigen内部存储顺序影响。✓
