## 2. 核心组件说明

### 2.1 CSVCaptureReader - CSV数据读取器

**功能**: 读取CSV文件并解析为`RigidBodyCaptureData`结构

**CSV格式**:
```csv
FrameNumber,TimeStamp_ms,TimeFromStart_s,X_mm,Y_mm,Z_mm,QX,QY,QZ,QW,RX_rad,RY_rad,RZ_rad
1,1737956123456,0.000000,-100.50,200.30,150.20,0.0000,0.0000,0.0000,1.0000,0.0000,0.0000,0.0000
2,1737956123457,0.001000,-100.48,200.32,150.18,0.0001,0.0002,0.0003,0.9999,0.0006,0.0004,0.0006
...
```

**列定义**:
| 列名 | 类型 | 说明 |
|------|------|------|
| FrameNumber | int | 帧序号 (从1开始) |
| TimeStamp_ms | long | Unix时间戳 (毫秒) |
| TimeFromStart_s | double | 从录制开始的相对时间 (秒) |
| X_mm, Y_mm, Z_mm | double | 位置坐标 (毫米) |
| QX, QY, QZ, QW | double | 四元数姿态 |
| RX_rad, RY_rad, RZ_rad | double | 旋转矢量 (弧度) |

## 4. 详细实现流程

### 4.1 步骤1: CSV文件加载

**入口函数**: `RigidBodyServojController.LoadCaptureData()`

```csharp
private bool LoadCaptureData()
{
    // 1. 验证文件路径
    if (string.IsNullOrEmpty(csvFilePath))
    {
        Debug.LogError("CSV文件路径未设置!");
        return false;
    }
    
    // 2. 验证文件存在
    if (!File.Exists(csvFilePath))
    {
        Debug.LogError($"CSV文件不存在: {csvFilePath}");
        return false;
    }
    
    // 3. 调用CSV读取器
    captureData = CSVCaptureReader.LoadFromCsv(csvFilePath);
    
    // 4. 验证数据有效性
    if (captureData == null || captureData.FrameData == null)
    {
        Debug.LogError("CSV数据解析失败!");
        return false;
    }
    
    return true;
}
```

### 4.2 步骤2: CSV解析过程

**核心函数**: `CSVCaptureReader.LoadFromCsv()`

```csharp
public static RigidBodyCaptureData LoadFromCsv(string filePath)
{
    // 读取所有行
    string[] lines = File.ReadAllLines(filePath);
    
    // 跳过标题行
    for (int i = 1; i < lines.Length; i++)
    {
        string[] values = lines[i].Split(',');
        
        // 解析每列数据
        FrameData frame = new FrameData
        {
            FrameNumber = int.Parse(values[0]),
            UnixTimeStamp = long.Parse(values[1]),
            Position = new PositionData
            {
                X = double.Parse(values[3]),  // X_mm
                Y = double.Parse(values[4]),  // Y_mm
                Z = double.Parse(values[5])   // Z_mm
            },
            Quaternion = new QuaternionData
            {
                X = double.Parse(values[6]),  // QX
                Y = double.Parse(values[7]),  // QY
                Z = double.Parse(values[8]),  // QZ
                W = double.Parse(values[9])   // QW
            }
        };
        
        captureData.FrameData.Add(frame);
    }
    
    return captureData;
}
```

### 4.3 步骤3: 启动回放协程

**函数**: `RigidBodyServojController.StartPlayback()`

```csharp
public void StartPlayback()
{
    if (captureData == null || captureData.FrameData.Count == 0)
    {
        Debug.LogError("没有可播放的数据!");
        return;
    }
    
    // 如果已有协程在运行，先停止
    if (playbackCoroutine != null)
    {
        StopCoroutine(playbackCoroutine);
    }
    
    // 重置帧索引
    currentFrameIndex = 0;
    isPlaying = true;
    isPaused = false;
    
    // 启动回放协程
    playbackCoroutine = StartCoroutine(PlaybackCoroutine());
}
```

### 4.4 步骤4: 回放协程主循环

**核心协程**: `RigidBodyServojController.PlaybackCoroutine()`

```csharp
private IEnumerator PlaybackCoroutine()
{
    // 计算帧间隔时间
    float frameInterval = 1.0f / playbackFrequency;
    
    while (currentFrameIndex < captureData.FrameData.Count)
    {
        // 暂停检测
        while (isPaused)
        {
            yield return null;
        }
        
        // 停止检测
        if (!isPlaying)
            yield break;
        
        // 获取当前帧
        FrameData frame = captureData.FrameData[currentFrameIndex];
        
        // 发送命令到机器人
        if (sendToRobot)
        {
            SendCommandToUR(frame);
        }
        
        // 更新UI (进度、当前帧信息等)
        UpdatePlaybackUI(frame);
        
        // 递增帧索引
        currentFrameIndex++;
        
        // 等待下一帧
        yield return new WaitForSeconds(frameInterval);
    }
    
    // 回放完成
    OnPlaybackComplete();
}
```

### 4.5 步骤5: 生成URScript命令

**函数**: `RigidBodyServojCommandGenerator.GenerateServojCommand()`

```csharp
public static string GenerateServojCommand(
    FrameData frame, 
    ServojParameters parameters,
    double[] currentJoints)
{
    // 1. 获取位置 (m)
    Vector3 pos = frame.GetPosition();
    
    // 2. 获取旋转矢量 (rad)
    Vector3 rot = frame.GetRotationVector();
    
    // 3. 格式化位姿字符串 p[x,y,z,rx,ry,rz]
    string poseStr = string.Format(
        CultureInfo.InvariantCulture,
        "p[{0:F6},{1:F6},{2:F6},{3:F6},{4:F6},{5:F6}]",
        pos.x, pos.y, pos.z,
        rot.x, rot.y, rot.z
    );
    
    // 4. 格式化当前关节角度 qnear
    string jointsStr = string.Format(
        CultureInfo.InvariantCulture,
        "qnear=[{0:F4},{1:F4},{2:F4},{3:F4},{4:F4},{5:F4}]",
        currentJoints[0], currentJoints[1], currentJoints[2],
        currentJoints[3], currentJoints[4], currentJoints[5]
    );
    
    // 5. 生成完整URScript命令
    string command = string.Format(
        CultureInfo.InvariantCulture,
        "servoj(get_inverse_kin({0}, {1}), a={2:F2}, v={3:F2}, t={4:F4}, lookahead_time={5:F2}, gain={6:F0})",
        poseStr,
        jointsStr,
        parameters.Acceleration,
        parameters.Velocity,
        parameters.TimeStep,
        parameters.LookAheadTime,
        parameters.Gain
    );
    
    return command;
}
```

}

## 5. 关键代码解析

### 5.1 四元数到旋转矢量转换

UR机器人使用旋转矢量（轴角表示法）而非四元数，需要进行转换：

```csharp
/// <summary>
/// 将四元数转换为旋转矢量 (轴角表示)
/// 旋转矢量 = 旋转轴 × 旋转角度
/// </summary>
public Vector3 GetRotationVector()
{
    Quaternion q = GetQuaternion();
    
    // 计算旋转角度 (弧度)
    float angle = 2.0f * Mathf.Acos(q.w);
    
    // 计算旋转轴的缩放因子
    float s = Mathf.Sqrt(1.0f - q.w * q.w);
    
    // 避免除零 (当角度接近0时)
    if (s < 0.001f)
        return Vector3.zero;
    
    // 旋转矢量 = 归一化轴 × 角度
    return new Vector3(
        q.x / s * angle,
        q.y / s * angle,
        q.z / s * angle
    );
}
```

**数学原理**:
- 四元数: $q = (w, x, y, z) = (\cos(\theta/2), \sin(\theta/2) \cdot \vec{n})$
- 旋转矢量: $\vec{r} = \theta \cdot \vec{n}$
- 其中 $\theta$ 是旋转角度，$\vec{n}$ 是归一化旋转轴

### 5.2 单位转换

| 数据类型 | CSV单位 | UR需求单位 | 转换公式 |
|----------|---------|------------|----------|
| 位置 | mm | m | $x_m = x_{mm} / 1000$ |
| 速度 | mm/s | m/s | $v_{m/s} = v_{mm/s} / 1000$ |
| 加速度 | mm/s² | m/s² | $a_{m/s²} = a_{mm/s²} / 1000$ |
| 旋转 | 弧度 | 弧度 | 无需转换 |

### 5.3 协程时序控制

```csharp
// 精确的帧间隔控制
float frameInterval = 1.0f / playbackFrequency;  // 例: 1/500 = 0.002s = 2ms

// Unity协程等待
yield return new WaitForSeconds(frameInterval);
```

**注意**: Unity的`WaitForSeconds`受`Time.timeScale`影响，实际精度约为帧率的倒数（通常16ms@60FPS）。对于高精度需求，可考虑使用`Time.realtimeSinceStartup`进行自定义计时。

| LookAheadTime | float | 0.03-0.2 | 0.1 | 前瞻时间 (s) |
| Gain | float | 100-2000 | 300 | 伺服增益 |

### 6.3 参数调优建议

**高速运动场景**:
```csharp
parameters.Acceleration = 3.0f;     // 增加加速度
parameters.Velocity = 2.0f;         // 增加速度
parameters.TimeStep = 0.004f;       // 减小时间步长
parameters.Gain = 500f;             // 增加增益
```

**平滑运动场景**:
```csharp
parameters.Acceleration = 0.8f;     // 降低加速度
parameters.Velocity = 0.5f;         // 降低速度
parameters.LookAheadTime = 0.15f;   // 增加前瞻时间
parameters.Gain = 200f;             // 降低增益
```

## 8. 常见问题与调试

### 8.1 CSV加载失败

**症状**: 控制台显示"CSV数据解析失败"

**可能原因**:
1. 文件路径错误
2. CSV格式不符合标准格式
3. 数据中存在非法字符

**解决方案**:
```csharp
// 检查文件是否存在
Debug.Log($"文件是否存在: {File.Exists(csvFilePath)}");

// 检查第一行内容
string[] lines = File.ReadAllLines(csvFilePath);
Debug.Log($"标题行: {lines[0]}");
Debug.Log($"数据行数: {lines.Length - 1}");
```

### 8.2 回放卡顿

**症状**: 机器人运动不流畅

**可能原因**:
1. 回放频率与录制频率不匹配
2. Unity帧率过低
3. TCP通信延迟

**解决方案**:
- 确保`playbackFrequency`与录制时的采样率一致
- 检查Unity目标帧率设置
- 使用异步TCP发送

### 8.3 位姿偏移

**症状**: 机器人运动轨迹与录制轨迹有偏差

**可能原因**:
1. 坐标系不匹配 (Tracker坐标系 vs 机器人基坐标系)
2. 单位转换错误
3. 标定误差

**解决方案**:
```csharp
// 添加坐标变换矩阵
Matrix4x4 calibrationMatrix = ...;
Vector3 transformedPos = calibrationMatrix.MultiplyPoint3x4(originalPos);
```

### 8.4 调试信息输出

开启详细日志:
```csharp
// 在Inspector中启用
showDebugInfo = true;

// 或在代码中
Debug.Log($"当前帧: {currentFrameIndex}/{totalFrames}");
Debug.Log($"位置: {frame.GetPosition()}");
Debug.Log($"旋转矢量: {frame.GetRotationVector()}");
Debug.Log($"URScript: {command}");
```
